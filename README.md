# Shubham Dudhal — Product Manager Portfolio

A clean, interactive career portfolio designed to showcase **Shubham Dudhal** as a **Product Manager** specializing in problem discovery, intuitive UX workflows, and cross-functional product execution, supported by a strong Computer Science foundation.

---

## ⚡ Key Highlights

- **Design Philosophy**: Minimalist, high-contrast aesthetic benchmarked against Taewoong Seo (`taewoongseo.com`), prioritizing clear typography, whitespace, and readability.
- **How I Build (The 5-Pillar Product Lifecycle)**:
  1. *Problem Discovery & Root-Cause Signal*
  2. *UX Discovery & Workflow Mapping*
  3. *Technical Feasibility & Alignment*
  4. *Sprint Execution & Cross-Squad Delivery*
  5. *QA Sanity, Edge Cases & Rollout Gates*
- **Featured Case Studies**:
  - *Fleet AI Query Assistant* (Roadcast)
  - *Voice AI Driver Safety Intercom* (Roadcast POC)
  - *Catalogue Cloud & SKU Variant Engine* (Fynd / Reliance)
  - *LinkedIn Mentorship Network* (Product Teardown & Figma Prototype)
- **The PM Craft & Execution Vault**: Tabbed, real-world execution breakdown covering problem validation, UX flows, schema scoping, edge-case hardening, and telemetry rollout gates.
- **Interactive Career Copilot**: Client-side interactive agent simulating instant Q&A on product philosophy, career milestones, and technical trade-offs.
